Project Overview

The Smart Dairy Livestock Monitoring and Decision Support System is a full-stack AI-powered web application built for dairy farm management. It brings together Machine Learning, Computer Vision (YOLOv8 + DeepSORT), and a modern clean web interface to deliver real-time health monitoring, behaviour surveillance, animal profile management, vaccination scheduling — all from one browser-based platform.

This system was developed as a Final Year Major Computer Science Project, demonstrating the real-world application of Artificial Intelligence in the AgriTech / Precision Farming domain.

System Modules
Module 01
Livestock Health Prediction
ML classification engine predicting Healthy or Sick/At Risk from 6 physiological parameters.
  • Random Forest, Decision Tree, Logistic Regression
  • Best model auto-selected by accuracy
  • Confidence %, risk level, recommendations
  • Save results to animal profile
  • Confusion matrix + feature importance
Module 02
Animal Behaviour Tracking
Real-time AI surveillance with YOLOv8 detection and DeepSORT multi-object tracking.
  • Webcam + video upload support
  • 6 behaviours: Resting, Feeding, Walking, Stress, Aggressive, Isolated
  • WARNING / CRITICAL alert engine
  • Live Chart.js behaviour + velocity charts
  • Manual Start / Stop toggle
Module 03
Animal Profile Manager
Full CRUD system for managing individual animal records with unique IDs and linked history.
  • Auto UID: SDMS-YYYY-NNNN
  • Health check history per animal
  • Weight trend chart (Chart.js)
  • Behaviour log from live tracking
  • Vaccination & treatment panels
Module 04
Vaccination & Treatment Scheduler
Full scheduling system for vaccinations and treatments with FullCalendar and overdue alerts.
  • FullCalendar interactive view
  • Auto overdue detection
  • Mark Done with vet & date
  • Treatment cost & dosage tracking
  • Linked to animal profiles
